# 🇰🇷 Korean Flashcards — интерактивный тренажер в Google Таблицах

Набор скриптов и шаблон Google Таблиц для изучения корейских слов через карточки, викторины и геймификацию. Всё работает прямо в браузере — никаких сторонних приложений, только Google Таблицы и Apps Script - https://docs.google.com/spreadsheets/d/1YX8igA9H3KvvcGnZ5v6I9QpvZIjxnjr8I9bQrAa3WBI/edit?usp=sharing

## ✨ Возможности

### 📚 Базовые режимы
- **Словарь** — база слов с корейским, русским переводом, частью речи и примерами.
- **Флеш-карточки** — показывает корейское слово, перевод скрыт до нажатия кнопки.
- **Умные порции** — генерация 10 случайных слов на день с сохранением прогресса.

### 🎮 Викторина
- **Режим KO → RU** — показывается корейское слово, выбираете русский перевод.
- **Режим RU → KO (наоборот)** — показывается русский перевод, выбираете корейское слово. Тренирует активное воспроизведение.
- **Диапазон строк** — можно учить только определённый блок слов (например, строки 2–15) или весь словарь.
- **Проверка ответа** — мгновенная обратная связь с правильным вариантом.

### 🧩 Режим «Собери слово из слогов»
- Показывается русский перевод и перемешанные корейские слоги.
- Нужно собрать правильный порядок и ввести ответ.
- Автоматически пропускает односложные слова.
- Кнопка «Подсказка» показывает правильный порядок.

### 🔥 Геймификация
- **Счёт очков** — за каждый правильный ответ +1.
- **Серия (Streak)** — счётчик правильных ответов подряд. При ошибке сбрасывается.
- **Рекорд серии** — сохраняется максимальная серия за всё время.
- **Уровни** — 🥚 Новичок → 🐣 Ученик → 🐥 Знаток → 🦅 Мастер → 🐉 Гуру корейского.
- **Счётчик ошибок** — общее количество неверных ответов.

### 🏁 Режим «Вызов» (Challenge Mode)
- «Сколько слов вы угадаете за 60 секунд?»
- Автоматически генерирует вопросы один за другим.
- Показывает оставшееся время и счётчик правильных ответов.
- В конце — итоговый результат.

### 📈 Прогресс
- Отметка слов как «Выучено» — они больше не попадаются в новых порциях.
- Хранение прогресса на отдельном листе, устойчиво к изменениям словаря.

## 📋 Требования

- Аккаунт Google (бесплатный).
- Браузер: Chrome, Firefox, Safari или Edge.
- Никаких сторонних библиотек или API-ключей — всё работает через встроенный Apps Script.

## 🚀 Установка

1. Создайте новую Google Таблицу.
2. Создайте **4 листа** с точными названиями:
   - `Словарь` — колонки A (корейский), B (русский).
   - `Карточки` — для флеш-карточек.
   - `Викторина` — для викторины.
   - `Собери слово` — для сборки из слогов.
   - `Вызов` — для режима «60 секунд».
   - `Прогресс` — для хранения выученных слов.
3. Откройте **«Расширения» → «Apps Script»**.
4. Вставьте код из файла `Code.gs` (см. папку `/scripts` этого репозитория).
5. Сохраните (Ctrl+S), закройте редактор и обновите таблицу (F5).
6. Создайте кнопки через **«Вставка» → «Рисунок»** и назначьте им скрипты (см. таблицу ниже).

| Кнопка | Скрипт | Где находится |
|---|---|---|
| Новая порция | `newBatch` | Лист «Карточки» |
| Показать перевод | `showTranslation` | Лист «Карточки» |
| Сохранить выученное | `markAsLearned` | Лист «Карточки» |
| Новый вопрос | `newQuestion` | Лист «Викторина» |
| Проверить | `checkAnswer` | Лист «Викторина» |
| Новое задание | `newBuildTask` | Лист «Собери слово» |
| Проверить | `checkBuildAnswer` | Лист «Собери слово» |
| 💡 Подсказка | `hintBuild` | Лист «Собери слово» |
| 🏁 Старт! | `startChallenge` | Лист «Вызов» |
| ⏹️ Стоп | `stopChallenge` | Лист «Вызов» |

## 🎯 Как пользоваться

### Ежедневное изучение слов (10 в день)
1. Откройте лист «Карточки».
2. Нажмите **«Новая порция»** — появятся 10 случайных слов.
3. Вспомните перевод, нажмите **«Показать перевод»**.
4. Если запомнили — напишите `Выучено` в столбце C.
5. Нажмите **«Сохранить выученное»** — слова уйдут в архив.

### Викторина
1. Введите диапазон строк (например, 2 и 15) или оставьте пустым для всего словаря.
2. Поставьте галочку в **E7** для режима RU → KO (сложнее).
3. Нажмите **«Новый вопрос»**, введите номер ответа в C2 и нажмите **«Проверить»**.
4. Следите за серией 🔥 и уровнем в столбце I.

### Сборка слова
1. Нажмите **«Новое задание»**.
2. Впишите собранное слово в C2 и нажмите **«Проверить»**.
3. Если не получается — нажмите **💡 Подсказка**.
